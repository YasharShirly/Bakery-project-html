# Bakery Project

A multi-page bakery web application built using HTML5 and CSS3.

---

## 🛠️ Tech Stack

- **HTML5:** Multi-page structure, semantic elements, and forms
- **CSS3:** Custom styles and layout design

---

## 📄 Pages & Features

- **Home Page:** Main showcase and catalog (`home-project.html`)
- **About Us:** Bakery story, branch locations, and club sign-up form (`zorkesher.html`)
- **Products:** Dedicated pages for sweets and salty pastries (`sweets.html`, `salty.html`)
- **Baking Tools:** Equipment and baking accessories catalog (`baking-tools.html`)
- **Orders:** Online order form (`order.html`)
